从上到下：越来越短、礼貌词越来越少、语气词越来越多。变的不是语法，是你和对方的距离。

三件事决定档位
对谁×在哪×说还是写
对谁：上级 / 陌生人 / 同事 / 朋友 / 铁哥们。在哪：公文、告示、柜台、饭桌。说还是写：说可以短句加语气词，写要完整结构和连接词。
拿不准时往上取一档：多一个 ครับ 只是显得客气，少一个可能就是失礼。
换挡时，真正改的是下面三样；其余部分基本不动。

句子长度

เนื่องจาก…จึง…

书面向子完整、因果挂在一个句子里；口语拆成两句，用 เลย 收结果。

礼貌词 / 语气词

ครับ · นะ · สิ · ดิ

礼貌词越往下越少，语气词越往下越多；第 3 档靠 รบกวน / ช่วย / หน่อย / ครับ 四层缓冲。

称呼

คุณ → พี่ → เธอ → มึง

称呼比句子更容易得罪人；不确定时用 พี่/คุณ，或直接省略主语。

03 · GEARS 01–02

最正式的两档

这两档不是「更客气的口语」，是另一套写法：句子完整、连接词明确、几乎不带语气词。
01 公文 · 书信 写给机构、王室、不认识的人
长什么样
完整主谓宾，靠 ขอความกรุณา（恳请）、จึงเรียนมาเพื่อโปรดพิจารณา（兹呈请考虑）这类套语推进；不用 ครับ/ค่ะ 收尾，也不用语气词。
什么时候用
正式信件、合同、投诉函、给学校或政府部门的申请。落款另有一套固定说法。
例句
ขอความกรุณาตรวจสอบเอกสาร
恳请您核查文件
ข้าพเจ้าขอแสดงความนับถือ
谨致敬意（正式书信的落款套语，不是日常问候）
ทรงขอบใจทุกคนทุกฝ่าย
国王感谢「各方每一位」——ทรง 是王室专用动词前缀
最容易在这里犯的错不是「不够正式」，而是把这一档搬进日常：เนื่องจาก…จึง… 的结构写报告没问题，说给朋友像在念公文（见第 5 页）。
02 告示 · 规章 写给所有路过的人
长什么样
祈使句，主语缺席，动词打头。ห้าม（禁止）最硬；กรุณา（请）稍软；ห้าม 后面直接跟动作，不解释理由。
什么时候用
门口、电梯、厕所、停车场、公园的牌子；公司规章、活动须知。
例句
ห้ามทิ้งขยะ
禁止乱扔垃圾（清莱一间寺院的告示牌原文）
กรุณาปิดมือถือ
请关闭手机（同一档，但用 กรุณา 放软）
这一档最容易被误用成「对一个人下命令」。对着朋友说 ห้าม…，听起来不是提醒，是训人；要请人做事，退回第 3–4 档。
正式文本一眼可认的四个信号

完整句式

ประธาน + กริยา + กรรม

主谓宾齐，因果用连接词挂在同一句里，不靠上下文补。

固定套语

ขอความกรุณา

开头与结尾都有固定说法；套语本身承担一半的礼貌，不需要再加语气词。

敬语主语

ข้าพเจ้า

说自己用「本人」而不是 ผม/ฉัน；涉及王室另有 ทรง 这类专用前缀。

无语气词

ไม่ใช้ ครับ / นะ / สิ

句尾干净。加了反而像在写一封不认真的信。

检验：一段文字如果能直接念给朋友听，它就还不够正式；反过来，如果一句话必须念完才能听懂，它就不适合放进聊天。

04 · GEARS 03–05

日常的三档

这三档才是每天都在用的。它们的差别不在词汇量，在「缓冲」有多少层。
03 职场 · 服务 熟但不亲，要留余地
四层缓冲
รบกวน（打扰你）＋ ช่วย（帮忙）＋ หน่อย（一点点）＋ ครับ（句尾礼貌）。撤掉任何一层，句子就更直接一点。
什么时候用
同事、房东、店员、司机、医院柜台——认识，但还没到可以开玩笑的距离。
例句
รบกวนช่วยดูเอกสารให้หน่อยครับ
麻烦帮我看一下文件
รบกวนสอบถามหน่อยครับ
打扰一下，想问个事（柜台／电话开场）
ครับ 只负责句尾的礼貌，不负责句子的软硬。只说 ดูเอกสารให้หน่อยครับ 也礼貌，但比带 รบกวน/ช่วย 的版本更像在派活。
04 朋友 · 平辈 关系够近才去掉敬语
长什么样
保留 ช่วย…หน่อย 的请求框架，句尾换成 ได้มั้ย（可以吗）征询；ครับ 撤掉，靠语调兜住礼貌。
什么时候用
同龄朋友、熟悉的邻居、一起吃过几次饭的人。对上级用这一档，问题不在语法，在距离。
例句
ช่วยดูเอกสารให้หน่อยได้มั้ย
能帮我看下吗
ไปกินหมูกระทะป่ะ
去吃泰式烤肉不（ป่ะ 是口语邀请，不是疑问词）
05 熟人 · 网络 越短越亲，也越容易翻车
长什么样
三个词说完，动词打头，语气词收尾：ดิ（催）、ป่ะ（邀请）、เลย（直接）。礼貌词清零。
什么时候用
只对真熟人：一起长大的朋友、天天见的同事、家里人。对不熟的人用 ดิ，会被听成命令。
例句
ดูให้หน่อยดิ
帮我看下呗（带点催）
ฝนตกหนักมาก รถติดเลย
雨超大，直接堵死（对比第 3 页的书面版）
对上司用 มึง，语法没错，关系错了。กู/มึง 在密友之间是亲近，对象换错就是事故。
同一句请求，缓冲层数在变

04 朋友ช่วยดูเอกสารให้หน่อยได้มั้ย两层 + 征询

05 · THREE TRAPS

最常踩的三个坑

都不是语法错误，都是档位错误。下面每条都给「你写的 / 该写的 / 为什么」。
TRAP 01

把书面语搬进日常

你写的
เนื่องจากฝนตกหนัก การเดินทางจึงล่าช้า
该写的
ฝนตกหนักมาก รถติดเลย
为什么
书面语用 เนื่องจาก…จึง… 把因果挂在一个句子里；口语拆成两个短句，用 เลย 收尾。句子没错，是场合错了。
TRAP 02

把口语拼写写进公文

聊天里
คับ
公文里
ครับ
为什么
คับ 是口语发音的写法，不是新标准。正式文本、公文、考试仍写 ครับ——写错不是「时尚」，是穿拖鞋面试。
TRAP 03

对不该用的人用 มึง

对朋友
มึง 可以，语气还显亲近（但要看关系深浅和场合）
对上司
换成 พี่ / คุณ，或者干脆省略主语
为什么
同一句话，换一个称呼就从「哥们」变成「冒犯」。学泰语先学分人称，再学句子。
一条通用检查
写完一句话，问自己两件事：这句是写给谁看的、对方会不会需要读到第二遍才知道我在拒绝。第一件决定档位，第二件决定要不要加缓冲。

03 与 04 的分界

ครับ ↔ ได้มั้ย

留 ครับ 是承认「还不熟」；换成 ได้มั้ย 是把决定权交给对方。两者同时出现，就偏正式了。

04 与 05 的分界

ดิ

ดิ 一出现，句子就从「请求」变成「催促」。关系没到那一步，别用它。

判断标准只有一条：这句话说完，对方还需不需要替你补一层礼貌？

06 · PARTICLES

句尾语气词

泰语的「礼貌」大半落在句尾。它们没有一对一中文翻译，按「场景 + 例句」记，别记等号。
词作用例句注意
ครับ / ค่ะ句尾礼貌（男 / 女）รบกวนช่วยดูเอกสารให้หน่อยครับ礼貌的地板，不是万能软化剂；句子本身太硬时，加它也不够。
นะ软化、提醒ไปก่อนนะ我先走了哦。对上级用会显得过于亲昵。
สิ催、强调ทำสิ做啊。关系不够近时听起来像不耐烦。
ดิ随意催促ดูให้หน่อยดิ只对真熟人；对陌生人用会被听成命令。
ล่ะ「那…呢」แล้วเธอล่ะ那你呢。也常用于追问，语气随语调变。
หรอก多与否定连用ไม่รู้หรอก才不知道呢。单独用会显得敷衍。
ป่ะ口语邀请 / 确认ไปกินหมูกระทะป่ะ去吃烤肉不。书面写作 ป่ะ 或 หรือเปล่า，正式文本用后者。
เลย「于是 / 直接」รถติดเลย把结果直接甩出来，口语里替代书面因果结构。
怎么练
同一句话，录五个版本：去掉 ครับ、加上 นะ、换成 ดิ、拉长语调、加快语速。让泰国朋友听哪一版「能对老板说」——比背规则快。
同一个请求，三种收尾，温度差在这里
+ ครับช่วยดูเอกสารให้หน่อยครับ客气，仍然直接
+ ได้มั้ยช่วยดูเอกสารให้หน่อยได้มั้ย征询，把决定权交出去
+ ดิดูให้หน่อยดิ催促，只对熟人
ครับ / ค่ะ / คะ 的分工
ครับ：男性通用，陈述句与问句都用。ค่ะ：女性，用于陈述与回答。คะ：女性，用于提问与请求。 写错性别比写错档位更尴尬，因为对方听得出你不是「不熟」，而是「没注意」。

08 · PRACTICE

五道练习

不用写答案，出声说。说完再对页尾的参考。
1 · 判档位
你要请房东帮忙看一下合同里的一个条款。用哪一档？先说出你选的档位，再补一句完整的话。
2 · 改口语
把 เนื่องจากฝนตกหนัก การเดินทางจึงล่าช้า 改成能对同事说的版本。
3 · 改书面
把聊天里的 คับ 写进一封正式邮件，应该写什么？为什么不能照抄？
4 · 换缓冲
把 ดูเอกสารให้หน่อยครับ 依次加回 ช่วย、รบกวน，说出三句在语气上的差别。
5 · 反向判断
听到一句 ไปกินหมูกระทะป่ะ，对方大概率把你放在哪一档？如果换成对上司说，该怎么改？
参考（不是唯一答案）
1 第 3 档。例：รบกวนช่วยดูสัญญาให้หน่อยครับ——房东是「熟但不亲」，四层缓冲刚好。
2 ฝนตกหนักมาก รถติดเลย（拆句 + เลย 收尾）。
3 写 ครับ。คับ 是口语发音写法，不是新标准，正式文本照抄会被读成不认真。
4 只加 ครับ：礼貌但直接；加 ช่วย：变成请求；再加 รบกวน：先承认打扰，最软。
5 第 4–5 档（朋友／熟人）。对上司改：รบกวนช่วย…ด้วยครับ，或直接说 ไปทานหมูกระทะกันไหมครับ。
这套资料的边界
1）五档是教学框架，不是国家标准，也有教材只分三档。
2）本页与第 3–4 页的例句是按语法与常用搭配自拟的，没有逐句请母语者审校；发布或教学前值得请母语者听一遍。
3）第 7 页流行语的证据等级只到「泰媒盘点 + 搜索摘要」。
4）影片与音频为合成语音，只保证「可听懂」，语气词的说服力靠真人语调。
