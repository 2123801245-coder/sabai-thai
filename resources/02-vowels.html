十二对速查

九对单元音（สระเดี่ยว）＋ 三对复合元音（สระประสม）。左边短、右边长，音标只是提示，长度才是区别。
对短长提示音注意
01
a
อะอาa / aa最短的一对，长短差最大。
02
i
อิอีi / ii写在上方，不占行宽。
03
ue
อึอือue / uee中文没有这个元音，先学短的那一个。
04
u
อุอูu / uu写在下方。
05
e
เอะเอe / ee短的那一个多一个 ะ；带尾音时 ะ 脱落。
06
ae
แอะแอae / aee与上一对只差一个符号，别写串。
07
o
โอะโอo / oo有尾音时 ะ 消失：คน、นก（见 p.6）。
08
o̜
เอาะออo̜ / o̜o不是 โอะ/โอ 那一对：写法是 เ-าะ / -อ，例 เกาะ / กอ。
09
oe
เออะเออoe / oee用法少，先认字形。
10
ia
เอียะเอียia复合元音，短的那版少见。
11
uea
เอือะเอือuea同上，先认长的。
12
ua
อัวะอัวua短的那版几乎只在口语词里出现。
三句话记住这张表
1）长短成对出现，不是零散记号：单元音 9 对，复合元音 3 对。
2）长音不等于拖长：短音要读得真的短，不是「短一点点」，否则两词会混。
3）有尾音时，短的会消失：โอะ 遇到尾音写成 ไม่มี ะ（คน、นก），但读的还是短音。

03 · THE TWELVE

十二对分别是什么

前九对是单元音（สระเดี่ยว），后三对是复合元音（สระประสม）。复合元音的短版在口语里出现得少，先认长的。

单元音 · 前舌

อิ / อี · เอะ / เอ · แอะ / แอ

三对，从高到低。中文母语者最容易把 เอะ 读成「诶」的拖长版——短的那一个要收得干脆。

单元音 · 后舌

อะ / อา · อุ / อู · โอะ / โอ

三对。อะ/อา 是长短差最明显的一对，也是最好用的校准对。

单元音 · 中央

อึ / อือ · เออะ / เออ · เอาะ / ออ

三对。อึ 在中文里没有对应音，先把嘴形记住，别用「e」代替。

09九对单元音สระเดี่ยว · 18 个符号
怎么记
把 9 对按「嘴的位置」排成一列：前舌 3 对、中央 3 对、后舌 3 对。每一对里，长的那个通常就是短的去掉 ะ，或换成另一个固定符号（如 อิ → อี）。
最容易混的两处
เอะ / แอะ 只差一个 ็ 的位置感，写法完全不同；โอะ / เอาะ 一个是 โ-ะ，一个是 เ-าะ，字形像但音不同。
例词
จะ
将要（อะ 短）
จาน
盘子（อา 长，带尾音 น）
กิ
（拼读练习用音节，อิ 短）
เก
（拼读练习用音节，เอ 长）
不要用「音标长度」判断：泰文的短音是音质差异，不只是时长。读短音时嘴形更紧、收得更快，拖长版会把词读成另一个。
10三对复合元音สระประสม · เอีย เอือ อัว
是什么
一个音节里两个元音滑过去：เอีย（ia）、เอือ（uea）、อัว（ua）。学校口径把这三组按短/长并列，共 3 对。
短版在哪见
短版（เอียะ / เอือะ / อัวะ）多出现在口语词与拟声词里；阅读材料里出现频率远低于长版。
例词
เมีย
妻子（เอีย 长）
เสือ
老虎（เอือ 长）
ตัว
身体／量词「只」（อัว 长）
复合元音的短版不能靠「读快一点」实现：它有自己的符号（多一个 ะ）。把长版读快，听到的还是长版。
检验：把 9 对单元音按长短各读一遍，中间不留停顿。如果听起来像 18 个不同的音，顺序就对了。

A前三对：声调不变ปาก/ปัก · ตาก/ตัก · คน/โคน
这三对的声调相同，所以「长短」是它们唯一的区别。为什么相同？因为它们的尾音是 ก 或 น，按规则都落进同一类音节（见 p.5），调号也一样。
ปาก 与 ปัก 的注音在字典里分别是 bpaak 与 pàk，调号看起来不同——那是两套罗马化标记的差异（一个标长音、一个标调），不是泰语声调不同。判断声调请看调号与音节类别，不要看罗马字。
B第四对：声调也换ดู / ดุ
为什么这里会变
ดู 是长元音、无尾音 → 活音节（พยางค์เป็น），平声；ดุ 是短元音、无尾音 → 死音节（พยางค์ตาย），声调要按另一套算，落在低声。
一句话
长短不只换词，还可能把声调一起带走——但只有「没有尾音」时才这样。
对照
ฉันดูเขา
我看他（ดู，平声）
ถูกดุ
被骂（ดุ，低声）
听力练习法
让母语者或合成音连读 8 个词，你只判断「长还是短」，不判断意思。三遍之后再挂意义——先建立长度感，比一开始就背释义有效。

05 · LIVE & DEAD

长短如何改写声调

决定声调的是三件事一起看：声母类别、音节死活、调号。这一页只讲其中「死活」这一半，完整表见第 03 册。
พยางค์เป็น · 活音节 → 按正常规则算
长元音 / 有响尾音（น ม ง ย ว）
例如 ตา（眼睛）、ดู（看）、คน（人）。活音节才允许带调号 ่ ้ ๊ ๋。
พยางค์ตาย · 死音节 → 另一套算法
短元音（无尾音）/ 尾音是 ก ด บ
例如 ปัก、ดุ、นก。死音节一般不带调号，声调由「声母类别 + 长短」直接定。
情况死活例子结果
长元音、无尾音活ดู · ตา按活音节规则；ดู 为平声
短元音、无尾音死ดุ · จะ换成死音节公式；ดุ 为低声
尾音 ก ด บ（长短都算）死ปาก · ปัก两者同为死音节 → 声调相同
尾音 น ม ง ย ว活คน · โคน两者同为活音节 → 声调相同
这条规则最容易被误读成「短音一定变调」。它不是。变的是「按哪套公式算」，不是「一定换一个调」——ปาก / ปัก 都是死音节，声调就一样；ดู / ดุ 一个活一个死，才会分开。

为什么尾音 ก ด บ 特殊

แม่กก · แม่กด · แม่กบ

这三个尾音本身不带响音，音节「收得住」，所以不管元音长短都算死音节。这是 ปาก / ปัก 声调相同的原因。

为什么响尾音不算死

แม่กง · กน · กม · เกย · เกอว

ง น ม ย ว 能拖长，音节「拖得动」，算活音节；长短只影响元音本身，不再改公式。

判断顺序：先看有没有尾音 → 尾音是响音还是 ก ด บ → 没有尾音再看元音长短。三步走完，才轮到调号。

06 · SPELLING

符号会消失的三种情况

「看不到符号」不等于「读长音」。这一页是长短最常被骗的地方。
01สระลดรูป · 符号脱落有尾音时 ะ 消失
โอะ 遇到尾音，符号 ะ 不写出来，但读的还是短音。所以 คน 读 kon（短 o），不是 khoon。
同一现象的其他例子
นก（鸟）、ลด（减少）、ผม（我／头发）。
对照
คน
人 — 短 o，符号不写
โคน
树干下部 — 长 oo，符号写出来
写作时最容易在这里丢音：把 คน 写成 โคน 是另一个词；把 โคน 写成 คน 也是另一个词。
02สระเกิน · 自带尾音的四组อำ ใอ ไอ เอา
这四个符号本身已经含了尾音：อำ = อะ + ม，ใอ/ไอ = อะ + ย，เอา = อะ + ว。所以它们不再另配尾音，长度按长音处理。
同组还有
ฤ ฤๅ ฦ ฦๅ 也在这一组里；它们的读法随词而定，不按单一规则。
例词
น้ำ
水（อำ）
ใจ
心（ใอ）
ไป
去（ไอ）
เรา
我们（เอา）
不要拿这四组去套「长短对」：它们不属于 9 对单元音，也不属于 3 对复合元音，是单独一组写法。
03รร · 随词读不是固定一个音
รร 的读法取决于它后面跟什么辅音：多数情况读 อะ 加后面的辅音作尾音，个别词读 อัน。
不要做的事
别看到 รร 就当成「r 音重复」。它本质是一个元音符号的写法。
例词
สวรรค์
天堂（读 สะ-หวัน，รร 在这里读 อะ + 尾音）
ธรรม
法、 Dharma（读 ทำ，รร 与后面的 ม 合成 อัม）

罗马字的两个陷阱
1）同一个词在不同转写系统里长得不一样（ปาก = bpaak / pàak），不要用罗马字反推长短，回来看泰文符号。
2）带调号的罗马字（pàk、dù）标的是声调，不是长度；标长度的写法常双写元音字母（aa、ii、uu）。

08 · PRACTICE

五道练习

不用写答案，出声读。读完再对页尾参考。
1 · 找对子
把 คน 的长音版本写出来，并说出两者意思。
2 · 判死活
ปัก 是活音节还是死音节？为什么 ปาก 跟它声调相同？
3 · 找脱落
นก 里为什么看不到 ะ？它的元音是长还是短？
4 · 分辨写法
โอะ/โอ 与 เอาะ/ออ 各举一个词，说明它们为什么不是同一对。
5 · 听辨
让人连读 ดู · ดุ · ตาก · ตัก，你只判断长短，不判断意思。四个里哪两个是长音？
参考（不是唯一答案）
1 โคน：คน = 人，โคน = 树干下部。
2 死音节（短元音 + 尾音 ก）。ปาก 的尾音也是 ก，同样算死音节，所以两者声调相同。
3 因为有尾音 ก，โอะ 的 ะ 按规则脱落（สระลดรูป）；读的仍是短音，nók。
4 โต๊ะ（桌子，โอะ/โอ 组）与 เกาะ（岛，เอาะ/ออ 组）；写法分别是 โ-ะ 与 เ-าะ，音不同。
5 长音是 ดู、ตาก；短音是 ดุ、ตัก。
这套资料的边界
1）「9 对单元音 + 3 对复合元音」是泰国学校口径；语言学研究对个别元音的归类不完全一致，本册不声称这是唯一切分。
2）本册规则条目（สระลดรูป、สระเกิน、死活音节）来自 DLTV 等教学材料的检索片段，正文未逐字读过；发布前建议打开链接复核。
3）โคน 只找到 โคนต้นไม้ 复合词条，本册按该词条释义写「树干下部」。
4）词表中的罗马字是辅助标记，不同系统写法不同，不作为读音标准。
5）影片与音频为合成语音，只保证可听懂，长短的细微差别建议请母语者示范一遍。
