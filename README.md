## 产品内容

- 66 条日常口语、语气词、聊天反应和泰网热词
- 泰语、罗马音、中文释义、使用提醒与例句
- 按场景筛选、关键词搜索、泰语朗读
- 收藏表达、记录学习进度、按 1/2/4/7/15/30 天间隔递进的复习计划
- 自建词条，并导出 JSON 备份；可在换设备后导入恢复
- 内置 8 册深度学习资料、1427 条离线可搜索摘要和两份可打印 PDF 练习资料
- 内置 62,264 条 Phupha 泰语网页词频索引，可离线搜索并逐条加入待补语境词卡；数据源不含释义与例句，学习者可补齐后保存为个人词卡
- 完整词频数据随应用交付；来源为 PyThaiNLP / Phupha-Word-freq（Common Crawl 2025-07，CC0）。语料频率不代表日常口语频率或网络热度
- 手机和桌面自适应；数据保存在当前设备
- 内置 Sarabun 泰文圈体无衬线字体（400 / 500 / 600 / 700）（SIL Open Font License 1.1）；部署后首次访问会缓存页面和字体

## 使用与发布

1. 直接打开 `index.html` 可以使用词卡、完整内置词频索引和本地资料库；发音使用设备的泰语语音引擎；设备没有泰语语音时，该功能不可用。
2. 发布网页商品时，将整个 `thai-sabai` 文件夹部署到支持 HTTPS 的静态托管；首次在线访问后会缓存应用、资料册和 PDF，并可添加到主屏幕。
3. 发布下载包时，将整个文件夹压缩为 ZIP；保留 `fonts/`、`sw.js`、`manifest.webmanifest` 和 `icon.svg`。

## 商品文案

**商品名：** Sabai 泰语口语卡｜日常表达 × 泰网热词

**一句话介绍：** 不背课本句子，学会泰国人聊天真的会说的话。

**商品描述：** 不只是泰语词义表，而是为旅行和日常聊天准备的口语练习工具。66 条表达覆盖点餐、问路、寒暄、语气词与泰网热词；每条配罗马音、真实例句和适用提醒，避免只会翻译却不知道怎么接话。间隔复习帮助记住，自建词条和备份让词库可以继续长大。一次交付、无需订阅，内容与进度留在自己的设备。

**交付物：** 独立网页链接或 ZIP 下载包。

> 词条是学习整理示例。流行词会随社群和时间变化；商品正式售卖前，建议由泰语母语者复核词义、语气和罗马音，并逐步替换为真人录音。
